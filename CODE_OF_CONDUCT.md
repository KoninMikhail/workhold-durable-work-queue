# Code of Conduct

This is a personal project. Discussion happens in issues, pull requests, and
other spaces maintained for this repository.

## Expected

- Talk about the change, the code, and the product.
- Assume the other person is trying to help.
- Keep secrets, tokens, and personal data out of the thread.

## Not accepted

- Harassment, insults, or personal attacks.
- Publishing someone else's private information.
- A public issue for a vulnerability. Use [SECURITY.md](SECURITY.md).

## Reporting

Email [dev.konin@gmail.com](mailto:dev.konin@gmail.com). For a vulnerability,
follow [SECURITY.md](SECURITY.md).
